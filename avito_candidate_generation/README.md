# Avito candidate generation

Решение задачи кандидатогенерации для поиска услуг. Для каждого запроса выбираются 50 объявлений. Результат на проверке — `Recall@50 = 0.768439`.

## Подход

- Текст запроса объединяется с его параметрами, у объявления используются заголовок, параметры и описание.
- Sparse-часть состоит из word и character TF-IDF. Поиск ограничивается категорией и локацией запроса.
- Dense-часть — `paraphrase-multilingual-MiniLM-L12-v2`, дообученный на парах запрос–объявление через `MultipleNegativesRankingLoss`.
- В итог попадают 31 кандидат sparse-модели и 19 новых кандидатов dense-модели. Повторы удаляются.

Локальная выборка делится по полному поисковому контексту, поэтому одинаковые запросы не оказываются одновременно в train и validation. Лучший локальный `Recall@50` для ансамбля — `0.750527`.

При разборе данных нашлась опечатка в названиях колонок: в описании используется `infn`, а в parquet встречается `infm`. Загрузчик принимает оба варианта. Также перед сохранением проверяются число строк, уникальность идентификаторов и наличие объявлений в корпусе.

## Запуск

Нужен Python 3.12 и желательно CUDA GPU. Положите `train.parquet`, `benchmark_queries.parquet` и `benchmark_items.parquet` в `data/raw`.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\run.ps1
```

Готовый файл появится в корне проекта под именем `answer.csv`. Первый запуск скачивает базовую модель с Hugging Face и занимает заметно больше времени, следующие используют локальные артефакты.

Локальную проверку sparse-части можно запустить отдельно:

```powershell
.\.venv\Scripts\python.exe scripts/run_local_validation.py
```
